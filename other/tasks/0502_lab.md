## 2. ТЕОРЕТИЧЕСКАЯ ЧАСТЬ

### 2.1. Что такое MVVM?

**MVVM** (Model-View-ViewModel) — архитектурный паттерн, разделяющий приложение на три слоя:

| Слой | Компонент | Описание |
|:---|:---|:---|
| **Model** | Данные и бизнес-логика | Репозитории, источники данных (БД, сеть). |
| **View** | UI | Composable-функции, отображающие состояние. |
| **ViewModel** | Посредник | Хранит состояние, обрабатывает события пользователя, взаимодействует с Model. |

**Схема взаимодействия:**

```
┌─────────────────────────────────────────────────────────┐
│                          View                           │
│  ┌─────────────────────────────────────────────────┐    │
│  │  @Composable fun CounterScreen(viewModel: VM)   │    │
│  │  val state by viewModel.state.collectAsState()  │    │
│  │  Button(onClick = { viewModel.increment() })    │    │
│  └─────────────────────────────────────────────────┘    │
│                         │  ↑                            │
│                         ▼  │                            │
│  ┌─────────────────────────────────────────────────┐    │
│  │                   ViewModel                      │    │
│  │  class CounterViewModel : ViewModel() {         │    │
│  │      private val _state = MutableStateFlow(0)   │    │
│  │      val state = _state.asStateFlow()           │    │
│  │      fun increment() { _state.update { it+1 } } │    │
│  │  }                                             │    │
│  └─────────────────────────────────────────────────┘    │
│                         │  ↑                            │
│                         ▼  │                            │
│  ┌─────────────────────────────────────────────────┐    │
│  │                    Model                         │    │
│  │  Репозитории, база данных, сетевые запросы      │    │
│  └─────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────┘
```

### 2.2. StateFlow и MutableStateFlow

**StateFlow** — реактивный поток данных, хранящий текущее состояние.

| Тип | Описание |
|:---|:---|
| `MutableStateFlow<T>` | Изменяемый поток (можно обновлять состояние). |
| `StateFlow<T>` | Неизменяемый поток (только для чтения). |

**Пример использования:**

```kotlin
class MyViewModel : ViewModel() {
    // Приватный изменяемый поток (только ViewModel может менять)
    private val _count = MutableStateFlow(0)
    
    // Публичный неизменяемый поток (UI подписывается)
    val count: StateFlow<Int> = _count.asStateFlow()
    
    fun increment() {
        _count.update { it + 1 }  // обновление состояния
    }
}
```

### 2.3. Подписка в Compose

```kotlin
@Composable
fun CounterScreen(viewModel: CounterViewModel) {
    // Подписка на поток — автоматическое обновление UI при изменении
    val count by viewModel.count.collectAsState()
    
    Text("Счётчик: $count")
    Button(onClick = { viewModel.increment() }) {
        Text("Увеличить")
    }
}
```

### 2.4. Преимущества MVVM

| Преимущество | Описание |
|:---|:---|
| **Разделение ответственности** | UI не содержит бизнес-логику. |
| **Тестируемость** | ViewModel легко тестировать без Android-зависимостей. |
| **Сохраняемость состояния** | ViewModel переживает поворот экрана. |
| **Реактивность** | UI автоматически обновляется при изменении данных. |

### 9.3. Пример сохранения состояния через SavedStateHandle

```kotlin
class CounterViewModel(
    private val savedStateHandle: SavedStateHandle
) : ViewModel() {
    private val _count = MutableStateFlow(
        savedStateHandle.get("count") ?: 0
    )
    
    fun increment() {
        _count.update { it + 1 }
        savedStateHandle["count"] = _count.value
    }
}
```
