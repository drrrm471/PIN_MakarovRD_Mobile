1. Освоить базовые компоненты Jetpack Compose: `Text`, `Button`, `Column`, `Row`, `Box`, `Image`, `Icon`.
2. Научиться использовать `Modifier` для стилизации и позиционирования элементов.
3. Освоить управление состоянием в Compose через `remember` и `mutableStateOf`.
4. Создать адаптивный экран профиля пользователя с интерактивными элементами.
5. Подготовить проект к дальнейшей интеграции с архитектурой MVVM (следующая ЛР).

## 2. ЗАДАНИЕ

### 2.1. Общее описание

Вам предстоит разработать **экран профиля пользователя** с использованием Jetpack Compose. Экран должен содержать:
- Аватар пользователя (иконка или изображение).
- Имя, статус и краткую информацию.
- Кнопки для взаимодействия.
- Возможность редактирования имени.

**Важно!** Вам выдаётся **50% готового кода** — шаблон с базовой структурой и заготовками Composable-функций. Ваша задача — доработать UI, добавить интерактивность и стилизацию.

## 5. ТРЕБОВАНИЯ К ОФОРМЛЕНИЮ

### 5.1. Требования к коду

1. **Документирование кода (KDoc):**
   - Все `@Composable`-функции должны иметь KDoc-комментарии.
   - Каждый параметр должен быть описан.
   - Должно быть указано назначение компонента.

2. **Стиль кода:**
   - Используйте `Modifier` для стилизации (не смешивайте с атрибутами).
   - Используйте `remember` и `mutableStateOf` для состояния.
   - Выносите повторяющиеся компоненты в отдельные функции.

3. **Разбивка на компоненты:**
   - `Avatar.kt` — только аватар.
   - `ProfileInfo.kt` — информация о пользователе.
   - `ActionButtons.kt` — кнопки.
   - `ProfileScreen.kt` — сборка всех компонентов.

### 8.2. Работа с изображениями в Compose

Для загрузки изображений из ресурсов:

```kotlin
import androidx.compose.ui.res.painterResource

// Использование картинки из ресурсов
Image(
    painter = painterResource(id = R.drawable.avatar),
    contentDescription = "Аватар пользователя",
    modifier = Modifier.size(120.dp).clip(CircleShape)
)
```

Для работы с иконками из Material Icons:

```kotlin
import androidx.compose.material.icons.Icons
import androidx.compose.material.icons.filled.Person

Icon(
    imageVector = Icons.Default.Person,
    contentDescription = "Иконка пользователя",
    modifier = Modifier.size(120.dp)
)
```

### 8.3. Пример использования TextField

```kotlin
@Composable
fun EditableName(
    name: String,
    onNameChange: (String) -> Unit
) {
    TextField(
        value = name,
        onValueChange = onNameChange,
        label = { Text("Имя") },
        modifier = Modifier.fillMaxWidth()
    )
}
```
