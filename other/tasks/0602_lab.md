## 2. ТЕОРЕТИЧЕСКАЯ ЧАСТЬ

### 2.1. Что такое Room?

**Room** — библиотека от Google, предоставляющая слой абстракции над SQLite. Она позволяет работать с базой данных через объекты Kotlin, а не через SQL-запросы вручную.

**Компоненты Room:**

| Компонент | Описание | Аннотация |
|:---|:---|:---|
| **Entity** | Класс, представляющий таблицу в БД. | `@Entity` |
| **DAO** | Интерфейс с методами доступа к данным. | `@Dao` |
| **Database** | Класс базы данных, связывающий Entity и DAO. | `@Database` |

**Схема работы Room:**

```
┌─────────────────────────────────────────────────────────┐
│                      Database                           │
│  ┌─────────────────────────────────────────────────┐    │
│  │  @Database(entities = [Task::class])            │    │
│  │  abstract class AppDatabase : RoomDatabase()    │    │
│  │  abstract fun taskDao(): TaskDao               │    │
│  └─────────────────────────────────────────────────┘    │
│                         │  ↑                            │
│                         ▼  │                            │
│  ┌─────────────────────────────────────────────────┐    │
│  │                      DAO                         │    │
│  │  @Dao interface TaskDao {                       │    │
│  │    @Insert suspend fun insert(task: Task)      │    │
│  │    @Query("SELECT * FROM tasks")               │    │
│  │    fun getAll(): Flow<List<Task>>              │    │
│  │  }                                             │    │
│  └─────────────────────────────────────────────────┘    │
│                         │  ↑                            │
│                         ▼  │                            │
│  ┌─────────────────────────────────────────────────┐    │
│  │                     Entity                       │    │
│  │  @Entity(tableName = "tasks")                  │    │
│  │  data class Task(                              │    │
│  │    @PrimaryKey(autoGenerate = true)            │    │
│  │    val id: Int = 0,                            │    │
│  │    val title: String,                          │    │
│  │    val isCompleted: Boolean = false            │    │
│  │  )                                             │    │
│  └─────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────┘
```

### 2.2. Преимущества Room

| Преимущество | Описание |
|:---|:---|
| **Типобезопасность** | Ошибки в SQL-запросах выявляются на этапе компиляции. |
| **Асинхронность** | Поддержка корутин и Flow. |
| **Миграция** | Упрощённое управление версиями базы данных. |
| **Интеграция** | Легко интегрируется с LiveData, Flow и ViewModel. |

package com.example.todolist.data

import androidx.room.Dao
import androidx.room.Delete
import androidx.room.Insert
import androidx.room.Query
import androidx.room.Update
import kotlinx.coroutines.flow.Flow

/**
 * DAO (Data Access Object) для работы с задачами.
 *
 * @author [ВАШЕ ИМЯ]
 * @since 2026-09-03
 */
@Dao
interface TaskDao {

    /**
     * Добавить новую задачу в базу данных.
     *
     * @param task Задача для добавления.
     * @return ID добавленной задачи.
     */
    @Insert
    suspend fun insert(task: Task): Long

    /**
     * Обновить существующую задачу.
     *
     * @param task Задача с обновлёнными данными.
     */
    @Update
    suspend fun update(task: Task)

    /**
     * Удалить задачу из базы данных.
     *
     * @param task Задача для удаления.
     */
    @Delete
    suspend fun delete(task: Task)

    /**
     * Получить все задачи в виде Flow (реактивное обновление).
     *
     * @return Поток списка всех задач, отсортированных по дате создания.
     */
    @Query("SELECT * FROM tasks ORDER BY createdAt DESC")
    fun getAllTasks(): Flow<List<Task>>

    /**
     * Получить задачи по статусу выполнения.
     *
     * @param isCompleted Статус выполнения.
     * @return Поток списка задач с указанным статусом.
     */
    @Query("SELECT * FROM tasks WHERE isCompleted = :isCompleted")
    fun getTasksByStatus(isCompleted: Boolean): Flow<List<Task>>
}

package com.example.todolist.data

import android.content.Context
import androidx.room.Database
import androidx.room.Room
import androidx.room.RoomDatabase

/**
 * Класс базы данных приложения.
 *
 * @author [ВАШЕ ИМЯ]
 * @since 2026-09-03
 */
@Database(
    entities = [Task::class],
    version = 1,
    exportSchema = false
)
abstract class AppDatabase : RoomDatabase() {

    abstract fun taskDao(): TaskDao

    companion object {
        @Volatile
        private var INSTANCE: AppDatabase? = null

        /**
         * Получить экземпляр базы данных (синглтон).
         *
         * @param context Контекст приложения.
         * @return Экземпляр AppDatabase.
         */
        fun getInstance(context: Context): AppDatabase {
            return INSTANCE ?: synchronized(this) {
                val instance = Room.databaseBuilder(
                    context.applicationContext,
                    AppDatabase::class.java,
                    "task_database"
                ).build()
                INSTANCE = instance
                instance
            }
        }
    }
}

package com.example.todolist.data

import kotlinx.coroutines.flow.Flow

/**
 * Репозиторий для работы с задачами.
 * Инкапсулирует доступ к базе данных.
 *
 * @param taskDao DAO для работы с задачами.
 *
 * @author [ВАШЕ ИМЯ]
 * @since 2026-09-03
 */
class TaskRepository(
    private val taskDao: TaskDao
) {

    /**
     * Получить все задачи.
     */
    fun getAllTasks(): Flow<List<Task>> = taskDao.getAllTasks()

    /**
     * Добавить новую задачу.
     */
    suspend fun insertTask(task: Task) {
        taskDao.insert(task)
    }

    /**
     * Обновить задачу.
     */
    suspend fun updateTask(task: Task) {
        taskDao.update(task)
    }

    /**
     * Удалить задачу.
     */
    suspend fun deleteTask(task: Task) {
        taskDao.delete(task)
    }

    /**
     * Изменить статус выполнения задачи.
     */
    suspend fun toggleTaskCompletion(task: Task) {
        val updatedTask = task.copy(isCompleted = !task.isCompleted)
        updateTask(updatedTask)
    }
}

### 5.1. Требования к коду

1. **Документирование кода (KDoc):**
   - Все Entity, DAO, Database, Repository, ViewModel должны быть документированы.
   - Все публичные методы должны иметь KDoc.

2. **Структура данных:**
   - Используйте `data class` для Entity.
   - Используйте `@PrimaryKey(autoGenerate = true)` для автогенерации ID.

3. **Асинхронность:**
   - Все операции с БД должны выполняться в корутинах (`suspend` или `Flow`).
   - Используйте `viewModelScope` для запуска корутин в ViewModel.

4. **Реактивность:**
   - UI должен обновляться автоматически при изменении данных через `StateFlow`.

Приложение для ведения списка задач с сохранением данных в локальной базе данных.

- **UI:** Jetpack Compose

- **База данных:** Room

- Добавление новых задач.
- Отметка задачи как выполненной.
- Удаление задачи.
- Автоматическое обновление списка.

## Структура проекта
- `data/` — Entity, DAO, Database, Repository.

### 8.2. Пример фабрики ViewModel

```kotlin
class TaskViewModelFactory(
    private val repository: TaskRepository
) : ViewModelProvider.Factory {
    override fun <T : ViewModel> create(modelClass: Class<T>): T {
        if (modelClass.isAssignableFrom(TaskViewModel::class.java)) {
            return TaskViewModel(repository) as T
        }
        throw IllegalArgumentException("Unknown ViewModel class")
    }
}
```

### 8.3. Использование в Compose

```kotlin
val context = LocalContext.current
val db = AppDatabase.getInstance(context)
val repository = TaskRepository(db.taskDao())
val viewModel: TaskViewModel = viewModel(
    factory = TaskViewModelFactory(repository)
)
```
