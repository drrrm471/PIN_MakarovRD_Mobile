## 2. ТЕОРЕТИЧЕСКАЯ ЧАСТЬ

### 2.1. Жизненный цикл Activity

Activity в Android имеет 6 основных состояний:

| Состояние | Метод | Описание |
|:---|:---|:---|
| **Создание** | `onCreate()` | Вызывается при первом создании Activity. Здесь инициализируют UI. |
| **Старт** | `onStart()` | Activity становится видимой для пользователя. |
| **Возобновление** | `onResume()` | Activity получает фокус и начинает взаимодействие с пользователем. |
| **Пауза** | `onPause()` | Activity теряет фокус (например, открывается диалог). |
| **Остановка** | `onStop()` | Activity полностью скрыта другим окном. |
| **Уничтожение** | `onDestroy()` | Activity уничтожается системой. |

**Важно для Compose:** При использовании Compose жизненный цикл управляется через `Lifecycle` и `remember`-функции, но базовые принципы остаются теми же.

### 2.2. Navigation в Compose

Navigation — компонент Jetpack для управления переходами между экранами.

**Основные элементы:**
- **NavHost** — контейнер для навигации.
- **NavController** — управляет навигацией.
- **Composable** — экраны, которые можно отображать.

**Схема навигации:**

```
┌─────────────────────────────────────────────┐
│                 NavHost                      │
│  ┌─────────────────────────────────────────┐ │
│  │          Список пользователей           │ │
│  │  ┌─────────────────────────────────┐    │ │
│  │  │   Пользователь 1  →  [Клик]    │    │ │
│  │  │   Пользователь 2  →  [Клик]    │    │ │
│  │  └─────────────────────────────────┘    │ │
│  └─────────────────────────────────────────┘ │
│                     │                         │
│                     ▼                         │
│  ┌─────────────────────────────────────────┐ │
│  │          Детальный экран                │ │
│  │  ┌─────────────────────────────────┐    │ │
│  │  │   Имя: Алексей                  │    │ │
│  │  │   Возраст: 25                   │    │ │
│  │  │   Город: Москва                 │    │ │
│  │  └─────────────────────────────────┘    │ │
│  └─────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

**Файл: `app/src/main/java/com/example/navigation/navigation/NavGraph.kt`**

```kotlin
package com.example.navigation.navigation

import androidx.compose.runtime.Composable
import androidx.navigation.NavType
import androidx.navigation.compose.NavHost
import androidx.navigation.compose.composable
import androidx.navigation.compose.rememberNavController
import androidx.navigation.navArgument
import com.example.navigation.screens.UserDetailScreen
import com.example.navigation.screens.UserListScreen

/**
 * Навигационный граф приложения.
 *
 * @author [ВАШЕ ИМЯ]
 * @since 2026-09-03
 */
@Composable
fun NavGraph() {
    val navController = rememberNavController()

    NavHost(
        navController = navController,
        startDestination = "user_list"
    ) {
        composable(route = "user_list") {
            UserListScreen(navController = navController)
        }

        composable(
            route = "user_detail/{userId}",
            arguments = listOf(
                navArgument("userId") { type = NavType.IntType }
            )
        ) { backStackEntry ->
            val userId = backStackEntry.arguments?.getInt("userId") ?: 0
            UserDetailScreen(
                userId = userId,
                navController = navController
            )
        }
    }
}
```

### 9.2. Пример передачи данных через аргументы

```kotlin
// Переход с передачей данных
navController.navigate("user_detail/${user.id}")

// Получение данных в детальном экране
composable(
    route = "user_detail/{userId}",
    arguments = listOf(navArgument("userId") { type = NavType.IntType })
) { backStackEntry ->
    val userId = backStackEntry.arguments?.getInt("userId") ?: 0
    UserDetailScreen(userId = userId, navController = navController)
}
```
