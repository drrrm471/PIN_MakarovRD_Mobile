## 2. ТЕОРЕТИЧЕСКАЯ ЧАСТЬ

### 2.1. Что такое PWA?

**Progressive Web App (PWA)** — это веб-приложение, которое использует современные браузерные технологии для предоставления пользовательского опыта, приближенного к нативным приложениям.

**Ключевые возможности PWA:**

| Возможность | Описание |
|:---|:---|
| **Установка** | Можно добавить на рабочий стол без магазина приложений. |
| **Офлайн-работа** | Работает без интернета благодаря Service Worker. |
| **Push-уведомления** | Может отправлять уведомления как нативное приложение. |
| **Доступ к API** | Геолокация, камера, акселерометр (через Web API). |
| **Безопасность** | Требуется HTTPS для работы Service Worker. |

### 2.3. Гибридные приложения

Гибридное приложение — это веб-приложение, упакованное в нативную оболочку (WebView).

| Инструмент | Описание |
|:---|:---|
| **Capacitor** | Современный инструмент от Ionic для создания гибридных приложений. |
| **Cordova** | Предшественник Capacitor. |
| **Ionic Framework** | UI-библиотека с компонентами под Android и iOS. |

**Сравнение подходов:**

| Критерий | PWA | Гибридное | Нативное |
|:---|:---|:---|:---|
| **Установка** | Через браузер | Магазин приложений | Магазин приложений |
| **Доступ к железy** | Ограниченный | Через плагины | Полный |
| **Производительность** | Средняя | Средняя | Высокая |
| **Офлайн-режим** | Да (Service Worker) | Да (Service Worker) | Да |
| **Push-уведомления** | Да | Да | Да |
| **Распространение** | Легкое (ссылка) | Модерация в магазинах | Модерация в магазинах |

**Файл: `js/app.js`**

```javascript
/**
 * Приложение «Список задач» (PWA)
 * 
 * @author [ВАШЕ ИМЯ]
 * @since 2026-09-03
 */

// ============ МОДЕЛЬ (Model) ============

const STORAGE_KEY = 'tasks_pwa';

/**
 * Класс для работы с задачами.
 * Хранит данные в localStorage.
 */
class TaskModel {
    constructor() {
        this.tasks = this.loadTasks();
        this.nextId = this.tasks.length > 0 
            ? Math.max(...this.tasks.map(t => t.id)) + 1 
            : 1;
    }

    /**
     * Загрузить задачи из localStorage.
     */
    loadTasks() {
        try {
            const data = localStorage.getItem(STORAGE_KEY);
            return data ? JSON.parse(data) : [];
        } catch {
            return [];
        }
    }

    /**
     * Сохранить задачи в localStorage.
     */
    saveTasks() {
        localStorage.setItem(STORAGE_KEY, JSON.stringify(this.tasks));
    }

    /**
     * Получить все задачи.
     */
    getAll() {
        return [...this.tasks];
    }

    /**
     * Добавить новую задачу.
     */
    add(title) {
        const task = {
            id: this.nextId++,
            title: title.trim(),
            completed: false,
            createdAt: Date.now()
        };
        this.tasks.push(task);
        this.saveTasks();
        return task;
    }

    /**
     * Переключить статус задачи.
     */
    toggle(id) {
        const task = this.tasks.find(t => t.id === id);
        if (task) {
            task.completed = !task.completed;
            this.saveTasks();
            return task;
        }
        return null;
    }

    /**
     * Удалить задачу.
     */
    delete(id) {
        this.tasks = this.tasks.filter(t => t.id !== id);
        this.saveTasks();
    }

    /**
     * Получить задачи по фильтру.
     */
    getFiltered(filter) {
        switch(filter) {
            case 'active': return this.tasks.filter(t => !t.completed);
            case 'completed': return this.tasks.filter(t => t.completed);
            default: return [...this.tasks];
        }
    }

    /**
     * Получить количество активных задач.
     */
    getActiveCount() {
        return this.tasks.filter(t => !t.completed).length;
    }
}

// ============ ПРЕДСТАВЛЕНИЕ (View) ============

class TaskView {
    constructor() {
        this.taskList = document.getElementById('taskList');
        this.taskInput = document.getElementById('taskInput');
        this.addButton = document.getElementById('addButton');
        this.taskCount = document.getElementById('taskCount');
        this.filterButtons = document.querySelectorAll('.filter-btn');
        this.onlineStatus = document.getElementById('onlineStatus');
    }

    /**
     * Отобразить список задач.
     */
    render(tasks, filter) {
        this.taskList.innerHTML = '';
        
        if (tasks.length === 0) {
            this.taskList.innerHTML = `
                <div style="text-align: center; padding: 40px 20px; color: #999;">
                    <div style="font-size: 48px; margin-bottom: 12px;">📭</div>
                    <p>Список задач пуст</p>
                    <p style="font-size: 14px; margin-top: 4px;">
                        ${filter === 'all' ? 'Добавьте новую задачу!' : 
                          filter === 'active' ? 'Все задачи выполнены! 🎉' : 
                          'Нет выполненных задач'}
                    </p>
                </div>
            `;
            return;
        }

        tasks.forEach(task => {
            const li = document.createElement('li');
            li.className = `task-item${task.completed ? ' completed' : ''}`;
            li.dataset.id = task.id;
            
            // Чекбокс
            const checkbox = document.createElement('div');
            checkbox.className = 'checkbox';
            checkbox.addEventListener('click', () => {
                this.onToggle(task.id);
            });
            
            // Название
            const title = document.createElement('span');
            title.className = 'task-title';
            title.textContent = task.title;
            
            // Кнопка удаления
            const deleteBtn = document.createElement('button');
            deleteBtn.className = 'task-delete';
            deleteBtn.textContent = '×';
            deleteBtn.addEventListener('click', () => {
                this.onDelete(task.id);
            });
            
            li.appendChild(checkbox);
            li.appendChild(title);
            li.appendChild(deleteBtn);
            this.taskList.appendChild(li);
        });
    }

    /**
     * Обновить счётчик задач.
     */
    updateCounter(count) {
        const text = count === 0 ? 'Нет задач' : 
                     count === 1 ? '1 задача' : 
                     count < 5 ? `${count} задачи` : 
                     `${count} задач`;
        this.taskList.textContent = text;
    }

    /**
     * Установить активный фильтр.
     */
    setActiveFilter(filter) {
        this.filterButtons.forEach(btn => {
            btn.classList.toggle('active', btn.dataset.filter === filter);
        });
    }

    /**
     * Получить текущий фильтр.
     */
    getCurrentFilter() {
        const active = document.querySelector('.filter-btn.active');
        return active ? active.dataset.filter : 'all';
    }

    /**
     * Обновить статус онлайн/офлайн.
     */
    setOnlineStatus(isOnline) {
        this.onlineStatus.textContent = isOnline ? '🟢 Онлайн' : '🔴 Офлайн';
        this.onlineStatus.style.color = isOnline ? 'green' : 'red';
    }

    /**
     * Обработчики событий.
     */
    onAdd(callback) {
        this.addButton.addEventListener('click', callback);
        this.taskInput.addEventListener('keydown', (e) => {
            if (e.key === 'Enter') callback();
        });
    }

    onToggle(callback) {
        this._onToggle = callback;
    }

    onDelete(callback) {
        this._onDelete = callback;
    }

    onFilter(callback) {
        this.filterButtons.forEach(btn => {
            btn.addEventListener('click', () => {
                this.filterButtons.forEach(b => b.classList.remove('active'));
                btn.classList.add('active');
                callback(btn.dataset.filter);
            });
        });
    }

    /**
     * Получить текст из поля ввода и очистить его.
     */
    getTaskInput() {
        const value = this.taskInput.value.trim();
        this.taskInput.value = '';
        this.taskInput.focus();
        return value;
    }

    /**
     * Показать уведомление (простой toast).
     */
    showToast(message) {
        // TODO: Реализовать toast-уведомление
        console.log(`[Toast] ${message}`);
    }
}

// ============ КОНТРОЛЛЕР (Controller / Presenter) ============

class TaskController {
    constructor() {
        this.model = new TaskModel();
        this.view = new TaskView();
        this.currentFilter = 'all';
        
        this.init();
    }

    init() {
        // Обработчики
        this.view.onAdd(() => this.addTask());
        this.view.onToggle((id) => this.toggleTask(id));
        this.view.onDelete((id) => this.deleteTask(id));
        this.view.onFilter((filter) => this.changeFilter(filter));
        
        // Статус сети
        this.view.setOnlineStatus(navigator.onLine);
        window.addEventListener('online', () => this.view.setOnlineStatus(true));
        window.addEventListener('offline', () => this.view.setOnlineStatus(false));
        
        // Регистрация Service Worker
        this.registerServiceWorker();
        
        // Первоначальный рендеринг
        this.render();
    }

    /**
     * Добавить задачу.
     */
    addTask() {
        const title = this.view.getTaskInput();
        if (!title) {
            this.view.showToast('Введите название задачи');
            return;
        }
        
        this.model.add(title);
        this.render();
    }

    /**
     * Переключить статус задачи.
     */
    toggleTask(id) {
        this.model.toggle(id);
        this.render();
    }

    /**
     * Удалить задачу.
     */
    deleteTask(id) {
        const task = this.model.tasks.find(t => t.id === id);
        if (task && confirm(`Удалить задачу "${task.title}"?`)) {
            this.model.delete(id);
            this.render();
        }
    }

    /**
     * Изменить фильтр.
     */
    changeFilter(filter) {
        this.currentFilter = filter;
        this.view.setActiveFilter(filter);
        this.render();
    }

    /**
     * Обновить представление.
     */
    render() {
        const filtered = this.model.getFiltered(this.currentFilter);
        const activeCount = this.model.getActiveCount();
        
        this.view.render(filtered, this.currentFilter);
        this.view.updateCounter(activeCount);
    }

    /**
     * Зарегистрировать Service Worker.
     */
    registerServiceWorker() {
        if ('serviceWorker' in navigator) {
            navigator.serviceWorker
                .register('sw.js')
                .then(registration => {
                    console.log('Service Worker зарегистрирован:', registration.scope);
                    
                    // Проверка обновлений
                    registration.addEventListener('updatefound', () => {
                        console.log('Новая версия Service Worker найдена');
                    });
                })
                .catch(error => {
                    console.error('Ошибка регистрации Service Worker:', error);
                });
        } else {
            console.log('Service Worker не поддерживается');
        }
    }
}
```

```javascript
/**
 * Service Worker для PWA «Список задач»
 * 
 * @author [ВАШЕ ИМЯ]
 * @since 2026-09-03
 */

const CACHE_NAME = 'pwa-todolist-v1';
const ASSETS = [
    '/',
    '/index.html',
    '/css/style.css',
    '/js/app.js',
    '/manifest.json',
    '/icons/icon-192.png',
    '/icons/icon-512.png'
];

// ============ Установка ============

self.addEventListener('install', event => {
    console.log('[SW] Установка...');
    
    event.waitUntil(
        caches.open(CACHE_NAME)
            .then(cache => {
                console.log('[SW] Кеширование ресурсов...');
                return cache.addAll(ASSETS);
            })
            .then(() => {
                console.log('[SW] Ресурсы закешированы');
                return self.skipWaiting();
            })
    );
});

// ============ Активация ============

self.addEventListener('activate', event => {
    console.log('[SW] Активация...');
    
    event.waitUntil(
        caches.keys()
            .then(keys => {
                return Promise.all(
                    keys.filter(key => key !== CACHE_NAME)
                        .map(key => {
                            console.log('[SW] Удаление старого кеша:', key);
                            return caches.delete(key);
                        })
                );
            })
            .then(() => {
                console.log('[SW] Кеш очищен');
                return self.clients.claim();
            })
    );
});

// ============ Перехват запросов ============

self.addEventListener('fetch', event => {
    event.respondWith(
        caches.match(event.request)
            .then(cachedResponse => {
                // Если ресурс есть в кеше — возвращаем его
                if (cachedResponse) {
                    // Проверяем, нужно ли обновить кеш (стратегия stale-while-revalidate)
                    if (event.request.method === 'GET') {
                        fetch(event.request)
                            .then(networkResponse => {
                                if (networkResponse.ok) {
                                    caches.open(CACHE_NAME)
                                        .then(cache => {
                                            cache.put(event.request, networkResponse);
                                        });
                                }
                            })
                            .catch(() => {});
                    }
                    return cachedResponse;
                }
                
                // Если нет в кеше — запрашиваем из сети
                return fetch(event.request)
                    .then(networkResponse => {
                        // Кешируем ответ для будущих запросов
                        if (networkResponse.ok && event.request.method === 'GET') {
                            const responseClone = networkResponse.clone();
                            caches.open(CACHE_NAME)
                                .then(cache => {
                                    cache.put(event.request, responseClone);
                                });
                        }
                        return networkResponse;
                    })
                    .catch(() => {
                        // Если сеть недоступна — показываем страницу офлайн
                        if (event.request.mode === 'navigate') {
                            return caches.match('/');
                        }
                        return new Response('Офлайн-режим', {
                            status: 503,
                            statusText: 'Service Unavailable'
                        });
                    });
            })
    );
});

// ============ Push-уведомления ============

self.addEventListener('push', event => {
    console.log('[SW] Получено push-уведомление:', event.data?.text());
    
    const data = event.data?.json() || {
        title: 'Уведомление',
        body: 'Новое сообщение',
        icon: '/icons/icon-192.png'
    };
    
    event.waitUntil(
        self.registration.showNotification(data.title, {
            body: data.body,
            icon: data.icon || '/icons/icon-192.png',
            badge: '/icons/icon-192.png',
            vibrate: [200, 100, 200],
            data: data.url || '/'
        })
    );
});

self.addEventListener('notificationclick', event => {
    event.notification.close();
    
    event.waitUntil(
        clients.matchAll({ type: 'window' })
            .then(windowClients => {
                // Если есть открытое окно — фокусируем его
                for (const client of windowClients) {
                    if (client.url === event.notification.data && 'focus' in client) {
                        return client.focus();
                    }
                }
                // Иначе открываем новое окно
                if (clients.openWindow) {
                    return clients.openWindow(event.notification.data || '/');
                }
            })
    );
});
```

### 5.1. Требования к коду

1. **Документирование:**
   - Все файлы должны иметь заголовки с описанием.
   - Код должен быть прокомментирован на русском или английском языке.

2. **Service Worker:**
   - Должен кешировать все статические ресурсы.
   - Должен работать в офлайн-режиме.
   - Должен обновлять кеш при новой версии.

3. **Manifest:**
   - Должен содержать все необходимые поля.
   - Должен поддерживать установку на устройство.
